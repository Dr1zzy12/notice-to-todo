# 课程通知转待办助手

把一段杂乱的课程/会议通知文本，解析成结构化的待办清单。纯前端单文件应用，打开即用。

**在线试用**：https://<你的用户名>.github.io/notice-to-todo/

## 功能

- **粘贴即解析**：课程名、日期时间、地点、截止时间自动抽取
- **原文依据对照**：每条待办可展开查看它来自原文哪一句，减少误判
- **规则引擎兜底**：AI 解析不确定时可一键切回规则引擎
- **导出 .ics**：生成日历文件，可分享 / 下载 / 复制内容
- **备份与导入**：全部待办导出为 JSON，换设备或清缓存前先备份
- **撤销与恢复**：误删、误清空可恢复上一次状态
- **可选接入 AI 智能体**：填写自己的 API 配置后启用更强的语义解析

## 特性

- 零依赖：单个 HTML 文件，无 CDN、无构建步骤
- 数据本地化：所有待办存在浏览器 localStorage，不上传服务器
- 移动端适配：针对微信内置浏览器做了号码识别和点击行为的处理

## 部署

这是纯静态页面，托管在 GitHub Pages 上：

1. 仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)`
4. 保存后访问 `https://<用户名>.github.io/notice-to-todo/`

## 本地运行

```bash
# 直接双击 index.html，或起个静态服务器
python -m http.server 8000
```
